    Ejercicio 1. Tienda de videojuegos

    Una tienda de videojuegos llamada GameZone quiere informatizar la gestión de su inventario. Actualmente dispone de varios videojuegos de distintas plataformas y necesita mantener actualizada la información sobre los precios y las unidades disponibles.

    Ejecuta el siguiente script en MySQL:

    CREATE DATABASE ud5_tienda_videojuegos;
USE ud5_tienda_videojuegos;

CREATE TABLE videojuegos (
    id INT PRIMARY KEY,
    titulo VARCHAR(100) NOT NULL,
    plataforma VARCHAR(30),
    precio DECIMAL(8,2),
    unidades INT
);

INSERT INTO videojuegos VALUES
(1, 'Elden Ring', 'PS5', 49.99, 12),
(2, 'Minecraft', 'PC', 24.99, 30),
(3, 'Zelda: Tears of the Kingdom', 'Switch', 59.99, 8),
(4, 'FIFA 26', 'PS5', 69.99, 20),
(5, 'Red Dead Redemption 2', 'PC', 29.99, 15);

    La tienda realiza varios cambios en su inventario, pero quiere asegurarse de que todos se puedan deshacer si hay algún problema.

    1. Inicia una transacción y realiza los siguientes cambios:
      • Aumenta en 5 unidades el stock de Minecraft.
      • Reduce el precio de FIFA 26 a 59,99 €.
      • Elimina Zelda: Tears of the Kingdom del inventario.
      • Inserta un nuevo videojuego:
        • ID: 6
        • Título: Cyberpunk 2077
        • Plataforma: PC
        • Precio: 39,99 €
        • Unidades: 10.
    2. Consulta todos los videojuegos.
    3. Ejecuta ROLLBACK.
    4. Vuelve a consultar la tabla.
    Solución 
    USE ud5_tienda_videojuegos;

START TRANSACTION;

-- Aumentar en 5 unidades el stock de Minecraft
UPDATE videojuegos
SET unidades = unidades + 5
WHERE titulo = 'Minecraft';

-- Reducir el precio de FIFA 26 a 59,99 €
UPDATE videojuegos
SET precio = 59.99
WHERE titulo = 'FIFA 26';

-- Eliminar Zelda: Tears of the Kingdom
DELETE FROM videojuegos
WHERE titulo = 'Zelda: Tears of the Kingdom';

-- Insertar Cyberpunk 2077
INSERT INTO videojuegos (id, titulo, plataforma, precio, unidades)
VALUES (6, 'Cyberpunk 2077', 'PC', 39.99, 10);

-- Consultar todos los videojuegos después de los cambios
SELECT * FROM videojuegos;

-- Deshacer todos los cambios de la transacción
ROLLBACK;

-- Volver a consultar la tabla para comprobar que se han deshecho los cambios
SELECT * FROM videojuegos;

    Ejercicio 2. Gestión de reservas de un hotel

    Un hotel llamado Hotel Costa Azul quiere informatizar la gestión de sus habitaciones y reservas. El establecimiento dispone de diferentes tipos de habitaciones, cada una con un precio por noche y un número determinado de unidades disponibles.

    Ejecuta el siguiente script en MySQL:

    CREATE DATABASE ud5_hotel;
USE ud5_hotel;

CREATE TABLE habitaciones (
    id INT PRIMARY KEY,
    tipo VARCHAR(50) NOT NULL,
    precio_noche DECIMAL(8,2),
    disponibles INT
);

CREATE TABLE reservas (
    id INT PRIMARY KEY,
    cliente VARCHAR(100) NOT NULL,
    id_habitacion INT,
    noches INT,
    FOREIGN KEY (id_habitacion) REFERENCES habitaciones(id)
);

INSERT INTO habitaciones VALUES
(1, 'Individual', 55.00, 8),
(2, 'Doble', 85.00, 12),
(3, 'Suite', 150.00, 4),
(4, 'Familiar', 120.00, 6),
(5, 'Deluxe', 180.00, 3);

INSERT INTO reservas VALUES
(1, 'Laura García', 2, 3),
(2, 'Carlos Martín', 1, 2),
(3, 'Ana López', 4, 5);

    El hotel necesita realizar las siguientes operaciones:

    1. Inicia una transacción.
    2. Registra una nueva reserva para Javier Sánchez, que ha reservado una habitación Suite durante 4 noches. Asígnale el identificador 4.
    3. Reduce el precio por noche de las habitaciones Deluxe a 160 €.
    4. Cancela la reserva de Carlos Martín.
    5. Registra una nueva reserva para María Fernández, que ha reservado una habitación Individual durante 2 noches. Asígnale el identificador 5.
    6. Consulta todas las habitaciones y reservas para comprobar los cambios.
    7. El responsable detecta que todavía no quiere aplicar estas modificaciones. Deshaz todas las operaciones mediante ROLLBACK.
    8. Consulta nuevamente las dos tablas y comprueba que han recuperado su estado inicial.
    Solución 
    USE hotel_costa_azul;

-- 1. Iniciar una transacción
START TRANSACTION;

-- 2. Registrar una reserva para Javier Sánchez
INSERT INTO reservas (id, cliente, id_habitacion, noches)
VALUES (4, 'Javier Sánchez', 3, 4);

-- 3. Reducir el precio por noche de las habitaciones Deluxe
UPDATE habitaciones
SET precio_noche = 160.00
WHERE tipo = 'Deluxe';

-- 4. Cancelar la reserva de Carlos Martín
DELETE FROM reservas
WHERE cliente = 'Carlos Martín';

-- 5. Registrar una reserva para María Fernández
INSERT INTO reservas (id, cliente, id_habitacion, noches)
VALUES (5, 'María Fernández', 1, 2);

-- 6. Consultar todas las habitaciones y reservas
SELECT * FROM habitaciones;
SELECT * FROM reservas;

-- 7. Deshacer todas las operaciones
ROLLBACK;

-- 8. Consultar nuevamente las tablas para comprobar
-- que han recuperado su estado inicial
SELECT * FROM habitaciones;
SELECT * FROM reservas;

    Ejercicio 3. Gestión de un concesionario de vehículos

    El concesionario MotorLux se dedica a la compraventa de vehículos nuevos y de segunda mano. Dispone de una base de datos para gestionar su catálogo de vehículos, los clientes y las operaciones de compraventa.

    Los comerciales registran las ventas cuando un cliente adquiere un vehículo. Además, deben actualizar el estado del vehículo para indicar que ya no está disponible y registrar el importe de la operación.

    El concesionario también acepta reservas de vehículos. En estos casos, el vehículo deja de estar disponible para otros compradores hasta que la reserva se confirme o se cancele.

    Durante una jornada de trabajo se producen varias ventas, reservas y modificaciones. El responsable administrativo quiere asegurarse de que todas las operaciones se realicen correctamente. Para ello, utilizará transacciones y puntos de control que permitan deshacer determinadas operaciones sin perder el resto de los cambios.

    Crea las siguientes tablas e introduce los datos que aparecen en estas:

    Tabla vehiculos

    id_vehiculo INT PK marca VARCHAR(50) NOT NULL modelo VARCHAR(50) NOT NULL año YEAR precio DECIMAL(10,2) NOT NULL estado VARCHAR(20) NOT NULL
    1 Toyota Corolla 2023 22500.00 Disponible
    2 BMW Serie 1 2022 28000.00 Disponible
    3 Seat León 2021 17500.00 Disponible
    4 Tesla Model 3 2024 39000.00 Disponible
    5 Volkswagen Golf 2020 19500.00 Reservado
    6 Renault Clio 2022 14500.00 Disponible
    7 Audi A3 2023 31500.00 Disponible

    Tabla clientes

    id_cliente INT PK nombre VARCHAR(100) NOT NULL telefono VARCHAR(15) ciudad VARCHAR(50)
    1 Laura Fernández 600111222 Valencia
    2 Daniel Martín 600222333 Madrid
    3 Paula Sánchez 600333444 Alicante
    4 Javier Romero 600444555 Valencia
    5 Elena Torres 600555666 Castellón

    Tabla ventas

    id_venta INT PK id_cliente INT FK id_vehiculo INT FK fecha DATE NOT NULL importe DECIMAL(10,2) NOT NULL
    1 2 5 2026-11-10 18500.00

    Tabla reservas

    id_reserva INT PK id_cliente INT FK id_vehiculo INT FK fecha DATE NOT NULL estado VARCHAR(20) NOT NULL
    1 3 4 2026-11-15 Pendiente
    Solución 
    CREATE DATABASE ud5_concesionario;
USE ud5_concesionario;

CREATE TABLE vehiculos (
    id_vehiculo INT PRIMARY KEY,
    marca VARCHAR(50) NOT NULL,
    modelo VARCHAR(50) NOT NULL,
    año YEAR,
    precio DECIMAL(10,2) NOT NULL,
    estado VARCHAR(20) NOT NULL
);

CREATE TABLE clientes (
    id_cliente INT PRIMARY KEY,
    nombre VARCHAR(100) NOT NULL,
    telefono VARCHAR(15),
    ciudad VARCHAR(50)
);

CREATE TABLE ventas (
    id_venta INT PRIMARY KEY,
    id_cliente INT,
    id_vehiculo INT,
    fecha DATE NOT NULL,
    importe DECIMAL(10,2) NOT NULL,
    FOREIGN KEY (id_cliente) REFERENCES clientes(id_cliente),
    FOREIGN KEY (id_vehiculo) REFERENCES vehiculos(id_vehiculo)
);

CREATE TABLE reservas (
    id_reserva INT PRIMARY KEY,
    id_cliente INT,
    id_vehiculo INT,
    fecha DATE NOT NULL,
    estado VARCHAR(20) NOT NULL,
    FOREIGN KEY (id_cliente) REFERENCES clientes(id_cliente),
    FOREIGN KEY (id_vehiculo) REFERENCES vehiculos(id_vehiculo)
);

INSERT INTO vehiculos VALUES
(1, 'Toyota', 'Corolla', 2023, 22500.00, 'Disponible'),
(2, 'BMW', 'Serie 1', 2022, 28000.00, 'Disponible'),
(3, 'Seat', 'León', 2021, 17500.00, 'Disponible'),
(4, 'Tesla', 'Model 3', 2024, 39000.00, 'Disponible'),
(5, 'Volkswagen', 'Golf', 2020, 19500.00, 'Reservado'),
(6, 'Renault', 'Clio', 2022, 14500.00, 'Disponible'),
(7, 'Audi', 'A3', 2023, 31500.00, 'Disponible');

INSERT INTO clientes VALUES
(1, 'Laura Fernández', '600111222', 'Valencia'),
(2, 'Daniel Martín', '600222333', 'Madrid'),
(3, 'Paula Sánchez', '600333444', 'Alicante'),
(4, 'Javier Romero', '600444555', 'Valencia'),
(5, 'Elena Torres', '600555666', 'Castellón');

INSERT INTO ventas VALUES
(1, 2, 5, '2026-11-10', 18500.00);

INSERT INTO reservas VALUES
(1, 3, 4, '2026-11-15', 'Pendiente');

    El concesionario consigue cerrar dos operaciones de compraventa:

    • Laura Fernández compra el Toyota Corolla por 21.500 €.
    • Daniel Martín compra el Renault Clio por 13.800 €.

    Realiza las siguientes operaciones:

    1. Inicia una transacción.
    2. Registra la venta del Toyota Corolla a Laura Fernández.
    3. Cambia el estado del Toyota Corolla a Vendido.
    4. Registra la venta del Renault Clio a Daniel Martín.
    5. Cambia el estado del Renault Clio a Vendido.
    6. Consulta las tablas para comprobar los cambios.
    7. Confirma todas las operaciones mediante COMMIT.
    Solución 
    START TRANSACTION;

-- Registrar la venta del Toyota Corolla a Laura Fernández
INSERT INTO ventas VALUES
(2, 1, 1, CURDATE(), 21500.00);

-- Cambiar el estado del Toyota Corolla
UPDATE vehiculos
SET estado = 'Vendido'
WHERE id_vehiculo = 1;

-- Registrar la venta del Renault Clio a Daniel Martín
INSERT INTO ventas VALUES
(3, 2, 6, CURDATE(), 13800.00);

-- Cambiar el estado del Renault Clio
UPDATE vehiculos
SET estado = 'Vendido'
WHERE id_vehiculo = 6;

-- Consultar las tablas para comprobar los cambios
SELECT * FROM ventas;
SELECT * FROM vehiculos;

-- Confirmar todas las operaciones
COMMIT;

    El concesionario consigue cerrar dos reservas:

    • El cliente Javier Romero quiere reservar el BMW Serie 1.
    • Posteriormente, Elena Torres solicita reservar el Audi A3.

    Realiza las siguientes operaciones:

    1. Inicia una nueva transacción.
    2. Registra una reserva para Javier Romero del BMW Serie 1, con estado Pendiente.
    3. Cambia el estado del BMW Serie 1 a Reservado.
    4. Crea un punto de control llamado reserva_bmw.
    5. Registra una reserva para Elena Torres del Audi A3, con estado Pendiente.
    6. Cambia el estado del Audi A3 a Reservado.
    7. Crea un punto de control llamado reserva_audi.
    8. Elena Torres comunica que finalmente no quiere reservar el Audi A3.
    9. Elimina su reserva y devuelve el estado del vehículo a Disponible.
    10. Consulta las tablas para comprobar los cambios.
    11. Deshaz las operaciones realizadas desde el punto de control reserva_bmw.
    12. Comprueba el estado final de las reservas y los vehículos.
    Solución 
    START TRANSACTION;

-- Registrar la reserva de Javier Romero para el BMW Serie 1
INSERT INTO reservas VALUES
(2, 4, 2, CURDATE(), 'Pendiente');

-- Cambiar el estado del BMW Serie 1
UPDATE vehiculos
SET estado = 'Reservado'
WHERE id_vehiculo = 2;

-- Crear el primer punto de control
SAVEPOINT reserva_bmw;

-- Registrar la reserva de Elena Torres para el Audi A3
INSERT INTO reservas VALUES
(3, 5, 7, CURDATE(), 'Pendiente');

-- Cambiar el estado del Audi A3
UPDATE vehiculos
SET estado = 'Reservado'
WHERE id_vehiculo = 7;

-- Crear el segundo punto de control
SAVEPOINT reserva_audi;

-- Eliminar la reserva de Elena Torres
DELETE FROM reservas
WHERE id_reserva = 3;

-- Devolver el estado del Audi A3 a Disponible
UPDATE vehiculos
SET estado = 'Disponible'
WHERE id_vehiculo = 7;

-- Consultar las tablas para comprobar los cambios
SELECT * FROM reservas;
SELECT * FROM vehiculos;

-- Deshacer las operaciones realizadas desde el punto de control reserva_bmw
ROLLBACK TO SAVEPOINT reserva_bmw;

-- Comprobar el estado final de las reservas y los vehículos
SELECT * FROM reservas;
SELECT * FROM vehiculos;

-- Confirmar las operaciones restantes
COMMIT;

    El cliente Laura Fernández comunica que existe un error administrativo en la venta de su Toyota Corolla. El concesionario decide anular la operación.

    Realiza las siguientes operaciones:

    1. Inicia una transacción.
    2. Elimina la venta correspondiente al Toyota Corolla.
    3. Cambia el estado del vehículo a Disponible.
    4. Crea un punto de control llamado anulacion_venta.
    5. El responsable detecta que también se debe modificar el precio del vehículo a 22.000 €.
    6. Realiza la modificación.
    7. Comprueba los datos mediante consultas.
    8. Deshaz únicamente la modificación del precio, manteniendo la anulación de la venta.
    9. Confirma los cambios mediante COMMIT.
    Solución 
    START TRANSACTION;

-- Eliminar la venta del Toyota Corolla
DELETE FROM ventas
WHERE id_venta = 2;

-- Cambiar el estado del Toyota Corolla a Disponible
UPDATE vehiculos
SET estado = 'Disponible'
WHERE id_vehiculo = 1;

-- Crear un punto de control
SAVEPOINT anulacion_venta;

-- Modificar el precio del Toyota Corolla a 22.000 €
UPDATE vehiculos
SET precio = 22000.00
WHERE id_vehiculo = 1;

-- Comprobar los datos mediante consultas
SELECT * FROM ventas;
SELECT * FROM vehiculos;

-- Deshacer únicamente la modificación del precio
ROLLBACK TO SAVEPOINT anulacion_venta;

-- Confirmar la anulación de la venta
COMMIT;

-- Consultar el estado final de las tablas
SELECT * FROM ventas;
SELECT * FROM vehiculos;
